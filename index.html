STL Mesh Editor

Version 1.0.0

Open STL files, repair them and get them ready to print – in the browser or as a Windows app.

  • Normal mode – move, rotate, resize, lay flat and export whole models
  • Edit mode – select, delete and split parts, close holes, group and ungroup
  • Cut mode – plane cuts with pins, holes or dowels, chosen automatically or placed by hand
  • Fix model – find floating parts and holes and fix them in one click

Press ? for all keyboard shortcuts. Built with Three.js. Everything runs on your computer – your models are never uploaded.

Click a model to select it (Shift adds, Ctrl removes), then move, rotate, resize, lay it flat or export it. Nothing selected = everything.

To change the model itself – delete or split parts, close holes, group or ungroup – switch to Edit (Tab). Leaving Edit makes the parts solid models again.

Shift adds, Ctrl removes. Drag on empty space to rotate the view. Group the selected parts into one model with Ctrl+G, ungroup with Ctrl+Shift+G.

Drag a rectangle over the model: it is cut cleanly along the rectangle's edges, all the way through, and the block inside is selected. Use a straight view (View ▾ → Top, Orthographic) for exact cuts, then Split it into its own part.

  1. Place the plane – drag the orb (arrow slides, rings tilt), pick an axis, or click the model.

    Shortcuts

    Modes

    • 1 = Normal (move, resize, export)
    • 2 = Edit (parts)
    • 3 = Cut
    • Tab = Normal ↔ Edit

    Tools

    • O = Select model / object
    • T = Triangle select
    • B = Brush select
    • X = Box select
    • P = Part select
    • G = Region select
    • K = Block cut & select
    • M = Move
    • R = Rotate on plate
    • Z = Resize
    • L = Lay flat
    • C = Cut / plane cut
    • Enter = Do the cut
    • V = View / orbit

    Edit

    • Del = Delete selection
    • S = Split into part
    • H = Close holes
    • W = Fix model
    • Ctrl+G = Group parts
    • Ctrl+Shift+G = Ungroup
    • Ctrl+Z = Undo
    • Ctrl+Y = Redo

    Selection

    • Ctrl+A = Select all
    • Ctrl+I = Invert
    • Esc = Select none
    • + / − = Grow / shrink
    • Shift+click = Add
    • Ctrl+click = Remove

    Move & rotate

    • ← → ↑ ↓ = Move on plate
    • PgUp / PgDn = Up / down
    • Shift+move = 10× step
    • Home = Centre on plate
    • Q / E = Turn left / right

    View

    • F = Frame model
    • Left-drag (empty space) = Turn around (left/right only)
    • Right-drag = Rotate freely
    • Middle-drag = Pan
    • Wheel = Zoom
    • Double-click = Rotation centre
    • ? = Show / hide this box

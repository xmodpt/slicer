Select tool

Drag left/right on the view to spin the model (or a selected split-off part) around its centre on the plate. Hold Shift to snap to 15°. Q / E rotate by the step set on the move pad.

Click a face of the model: the whole model turns as one group so that face (and the flat area around it) lies on the plate. To turn only some parts, select them first and click a face on them.

Plane

Pick a plane, then click the model or use the slider to place it (0 = automatic pin size). The cut closes both halves and adds pins on the lower half and matching holes in the upper half – Flip swaps them. Then move the halves apart and export them as separate parts.

Drag a rectangle: the model is cut along its edges, all the way through, and the block inside is selected. Use a straight view (Top, Front…) for straight cuts, then Split it into its own part.

Shift = add · Ctrl = remove · left-drag on empty space (any tool but Box/Block), left-drag with Object/Triangle/Part/Region, or right-drag rotates the view · middle-drag or Shift+right-drag pans · wheel zooms to the cursor · side buttons zoom · double-click sets the rotation centre · ? all shortcuts

    Shortcuts

    Tools

    • O = Object select
    • V = View / orbit
    • T = Triangle select
    • B = Brush select
    • X = Box select
    • K = Block cut & select
    • P = Part select
    • G = Region select
    • R = Rotate on plate
    • L = Lay flat
    • C = Cut / plane cut
    • Enter = Do the cut

    Edit

    • Del = Delete selection
    • S = Split into part
    • H = Close holes
    • Ctrl+Z = Undo
    • Ctrl+Y = Redo

    Selection

    • Ctrl+A = Select all
    • Ctrl+I = Invert
    • Esc = Select none
    • + / − = Grow / shrink
    • Shift+click = Add
    • Ctrl+click = Remove

    Move & rotate

    • ← → ↑ ↓ = Move on plate
    • PgUp / PgDn = Up / down
    • Shift+move = 10× step
    • Home = Centre on plate
    • Q / E = Turn left / right

    View

    • F = Frame model
    • Left-drag (empty space) = Rotate
    • Right-drag = Rotate
    • Middle-drag = Pan
    • Wheel = Zoom
    • Double-click = Rotation centre
    • ? = Show / hide this box

    Number keys 1–9, 0 also pick tools.

Shortcuts

Tools

  • O = Object select
  • T = Triangle select
  • B = Brush select
  • X = Box select
  • P = Part select
  • G = Region select
  • K = Block cut & select
  • M = Move
  • R = Rotate on plate
  • L = Lay flat
  • C = Cut / plane cut
  • Enter = Do the cut
  • V = View / orbit

Edit

  • Del = Delete selection
  • S = Split into part
  • H = Close holes
  • Ctrl+Z = Undo
  • Ctrl+Y = Redo

Selection

  • Ctrl+A = Select all
  • Ctrl+I = Invert
  • Esc = Select none
  • + / − = Grow / shrink
  • Shift+click = Add
  • Ctrl+click = Remove

Move & rotate

  • ← → ↑ ↓ = Move on plate
  • PgUp / PgDn = Up / down
  • Shift+move = 10× step
  • Home = Centre on plate
  • Q / E = Turn left / right

View

  • F = Frame model
  • Left-drag (empty space) = Rotate
  • Right-drag = Rotate
  • Middle-drag = Pan
  • Wheel = Zoom
  • Double-click = Rotation centre
  • ? = Show / hide this box
